# Relatório de Serviços Prestados - Consultoria

## 📊 Sobre o Projeto
Este projeto contém um dashboard desenvolvido no Power BI para a análise de serviços prestados por uma empresa de consultoria. O objetivo do relatório é fornecer uma visão clara e estratégica sobre o faturamento total, gasto salaria por área e a análise de contratos fechados por funcionários

## 🚀 Principais Indicadores e Visões
- **Faturamento total:** Acompanhar o faturamento total obtido sobre os contratos fechados.
- **Desempenho por funcionário:** Produtividade e alocação de equipe.
- **Demonstrativo da quantidade de funcionários por área**
- Ticket Médio por contrato.
- Cliente com o maior contrato em vigor com a empresa.

## 🛠️ Ferramentas Utilizadas
- **Power BI Desktop:** ETL, Modelagem de dados, cálculos em DAX e criação das visualizações.

## 📂 Como visualizar o dashboard
1. Faça o download do arquivo `.pbix` presente neste repositório.
2. Certifique-se de ter o [Power BI Desktop](https://powerbi.microsoft.com/desktop/) instalado no seu computador.
3. Abra o arquivo com o Power BI Desktop para interagir com os filtros e gráficos.
